# TaskFlow – SaaS Landing Page (Angular 22 + Tailwind CSS)

A modern, fully responsive landing page for a fictional project-management product.

**Live demo:** _coming soon_

## Features
- Sticky navbar with mobile menu
- Hero section with product mockup
- Feature grid, "how it works" steps and testimonials
- Pricing table with **monthly / yearly toggle** (20% yearly discount)
- FAQ accordion
- Contact form with validation and success state
- Smooth scrolling, hover animations, mobile-first layout

## Tech
Angular 22 (standalone components, signals, new control flow), TypeScript, Tailwind CSS 4.

## Run locally
```bash
npm install
npm start          # http://localhost:4200
npm run build      # production build in dist/saas-landing-page/browser
npm test
```
